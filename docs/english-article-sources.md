# 英文练习文章来源

英文库收录三部文集中的 21 篇完整小说与童话，每个难度各七篇。选材围绕爱情、友谊、亲情、成长、思念与失落。难度按阅读和输入负担分配，综合考虑词汇、句式、篇幅和叙事方式。

- O. Henry，[The Four Million](https://www.gutenberg.org/ebooks/2776)，1906 年。
- Katherine Mansfield，[The Garden Party, and Other Stories](https://www.gutenberg.org/ebooks/1429)，1922 年。
- Oscar Wilde，[The Happy Prince, and Other Tales](https://www.gutenberg.org/ebooks/902)，1888 年。

Project Gutenberg 将这三个电子版标注为在美国属于公有领域。下表链接定位到相应的故事章节。

练习正文按源版段落顺序提取，保留故事中的信件和告示，省去篇名、插图、版面装饰及电子书前后附文。段内排版空白折叠为单个空格，段落之间使用换行。为便于键盘输入，正文把弯引号替换为直引号，长短破折号替换为两个连字符，省略号替换为三个句点，重音字母转换为基础拉丁字母，乘号替换为 x。

词数将词内撇号和连字符视为词的一部分，独立数字不计入词数。字符数包含空格、标点和段落换行。
