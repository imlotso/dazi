# 统一登录与独立管理界面验收

用户选择从现有登录按钮按账号角色进入对应界面。此改动移除前台独立的“管理后台”导航项，并将管理员工作区从练习页组件中分离。

## 最终行为

- 普通账号登录后保留练习界面；管理员通过同一个登录表单进入独立管理界面。
- 已登录管理员访问首页或刷新时恢复管理界面；`/admin` 书签继续使用同一套登录流程。
- 管理界面保留蓝紫配色、原有管理功能与夜间主题，使用自己的页头和内容区域，不包含练习导航、房间插画、睡猫或打字控件。
- 管理员可显式“预览网站”，通过原账号位置的“返回管理”回到后台；活动练习先暂停保存。普通前台不提供管理操作。
- 明确退出后返回普通首页；账号或权限切换会清除前一个管理员的预览状态。

## 回归与审查

- 管理员与普通账号从统一入口登录，恢复管理员会话，退出与角色重验证。
- 管理员预览中的活动输入在返回/重新预览后保留。
- A→B→A 的管理员账号切换不恢复旧预览。
- 旧账号页面不能注销新账号；延迟的账号范围内退出响应不再清除后来登录设置的 Cookie。
- 新浏览器尚未读取账号偏好时不能用默认值覆盖云端设置；已有缓存的账号可离线调整。此保护同时覆盖普通练习页和管理界面。
- 书签会话检查期间不挂载练习页或管理数据。

独立审查提出的账号预览残留、退出响应竞态、提前写入偏好均先通过失败用例重现，再修复通过；同时把手机上的返回操作改为可见文字。
