# 管理员后台验收

范围：将原有成绩审核入口完善为独立管理员后台，保留既有蓝紫云朵房间风格和简洁文案。开发使用独立 worktree，背景功能先经 PR #2 合并，本轮后台独立集成。

## 已实现

- `/admin` 入口：未登录时进入登录，登录后验证数据库中的管理员权限。
- 概览：真实账号、近 7 天服务端练习、公开文章、待审核/已发布成绩和最近操作数据。
- 用户管理：用户名/邮箱搜索、角色/状态筛选、分页、账号摘要、停用/启用、授予/撤销管理员、退出全部会话。角色与状态修改同时失效会话和旧验证码；禁止自停用、自撤权和移除最后一位启用管理员。
- 文章管理：新建草稿、编辑、发布、归档、删除及来源/授权信息；已发布集合保持每种语言至少 20 篇并覆盖三个难度。发布要求每篇至少 1000 汉字或英文单词。并发修改检查文章版本；历史练习使用当时快照。
- 成绩管理：状态/语言/难度/搜索筛选，显示模式、规则和复核依据；单条或批量通过、拒绝、下架，必须确认原因。
- 操作日志：记录操作者、目标、动作、原因、时间；可搜索、按对象类型筛选和分页。不暴露用户私有文章、草稿或背景内容。
- 首任管理员初始化：`scripts/bootstrap-admin.mjs` 从标准输入读取密码，无需 SMTP，不覆盖已有用户或已有管理员。脚本已进入生产 Docker 镜像。

## 实际浏览器走查

在隔离的 `127.0.0.1:4183` 数据库中使用测试账号，通过实际 UI 验证：

1. 管理员可进入概览、用户、文章、成绩和日志页；本人详情不提供停用/撤权操作。
2. 创建 26 汉字短草稿，保存后状态为草稿；普通文章库搜索不到它。尝试发布时显示真实校验错误，未发布到公共文库。
3. 为通过正常练习 API 生成的待审核成绩填写原因并确认通过，已发布列表和操作日志均出现对应结果。
4. 对测试普通用户执行退出全部会话，活跃会话从 1 变为 0；操作日志保存同一目标和填写的原因。
5. 检查 1280 × 720 桌面与 375 × 812 手机夜间界面。手机页面宽度 360 px，没有横向溢出和 placeholder。
