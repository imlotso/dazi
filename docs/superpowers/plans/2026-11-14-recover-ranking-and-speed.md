# 恢复排行榜资格与速度说明

**目标：** 在线建档超时或离开页面后，恢复公开文章进度并可提交成绩；英文练习同时显示 WPM 和正确字符/分钟，并提供可点击说明。

**约束：** 未验证的离线进度只能进入人工复核；私人文章、其他账号、被删除草稿不得获得或接管别人的在线记录。保留首字计时、暂停时不计时和现有 WPM 排行口径。

1. 服务端按所有者和随机恢复凭证认领原练习；未建档时核验公开文章快照并创建待复核练习。测试超时、丢失访客 cookie、长时间离开、重复请求、账户隔离及成绩提交。
2. 客户端持久化恢复标识和凭证，在本地、账号同步草稿、暂停、恢复和结算时重连；网络仍不可用时保留完成结果供重试。测试输入和有效计时不丢失、断网重试、跨标签和跨设备隔离。
3. 在实时和成绩界面展示两种速度及可点击的计算说明；测试键盘、手机、日夜模式和现有成绩口径。
4. 检查实际浏览器流程与界面，运行完整单元、接口、浏览器、构建、Sites 和部署测试；提交 PR，等待 CI 后合并 main 并确认 main CI。
